When should the bot ask for Confirm?

Guided POS still needs a rule for “I fat-fingered that.” Pick the safety level.

A

Always confirm sale and stock (recommended)

Sale path: product → qty → customer → summary + Confirm / Cancel → create.
Stock path: product → new qty → Confirm → write.
Extra tap, fewer wrong orders. Cancel always returns to menu.

B

Confirm stock only; sale commits on contact

Sharing contact / typing phone creates the order immediately after a short summary message. Faster at the counter; harder to undo if the wrong product was picked earlier.

C

Confirm only when risk is high

e.g. stock set to 0, sale qty ≥ 5, or product has low stock. Otherwise auto-commit after last step. Smarter, more code and edge cases.

Locked: Guided POS · full menu · recent products first · dashboard connect (bot link later).
Lean: A — same mental model every time; fewer “why did it create that?” moments.
